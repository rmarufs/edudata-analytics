# GMDH / МГУА

Небольшая Python-библиотека для регрессии методом группового учета аргументов
(МГУА, GMDH). Библиотека строит модель из квадратичных полиномов, постепенно
создает новые слои признаков и оставляет только лучшие нейроны по качеству на
валидационной выборке.

## Идея метода

МГУА строит модель не как один большой полином сразу, а послойно:

1. Из исходных признаков берутся все пары признаков.
2. Для каждой пары обучается квадратичный нейрон:

   ```text
   y = a0 + a1*x1 + a2*x2 + a3*x1*x2 + a4*x1^2 + a5*x2^2
   ```

3. Каждый нейрон оценивается на валидационной части данных.
4. Лучшие нейроны становятся входами для следующего слоя.
5. Рост слоев останавливается, когда новый слой уже не улучшает качество.

Такой подход позволяет автоматически строить нелинейную регрессионную модель и
при этом ограничивать сложность через отбор лучших нейронов.

## Состав библиотеки

- `neuron.py` - один квадратичный нейрон МГУА.
- `layer.py` - слой нейронов, перебор пар признаков и отбор лучших.
- `model.py` - основной класс `GMDHRegressor`.
- `criteria.py` - метрики качества: `mse`, `rmse`, `mae`, `r2`.
- `__init__.py` - публичные импорты библиотеки.
- `test_gmdh_module.py` - самостоятельная проверка возможностей модуля.

## Быстрый пример

```python
import numpy as np
from gmdh import GMDHRegressor


rng = np.random.default_rng(42)
X = rng.normal(size=(150, 4))
y = 2.0 + 1.5 * X[:, 0] - 0.8 * X[:, 1] + 0.7 * X[:, 0] * X[:, 1]

model = GMDHRegressor(max_layers=4, top_n=6, random_state=42)
model.fit(X, y)

predictions = model.predict(X)
metrics = model.get_metrics(X, y)

print(metrics)
print(model.get_formula(["x0", "x1", "x2", "x3"]))
```

## Основной класс

Главный интерфейс библиотеки - `GMDHRegressor`.

```python
GMDHRegressor(
    max_layers=8,
    top_n=10,
    val_split=0.5,
    max_pairs_per_layer=300,
    random_state=None,
)
```

Параметры:

- `max_layers` - максимальное число слоев модели.
- `top_n` - сколько лучших нейронов оставлять после каждого слоя.
- `val_split` - доля данных для внутренней валидации.
- `max_pairs_per_layer` - ограничение числа пар признаков на одном слое. Это
  защищает от слишком большого перебора при большом числе признаков.
- `random_state` - фиксирует случайность при разбиении данных и выборе пар.

Основные методы:

- `fit(X, y)` - обучает модель.
- `predict(X)` - возвращает предсказания.
- `get_metrics(X, y)` - считает `mse`, `rmse`, `mae`, `r2`.
- `get_feature_importance(X, y)` - оценивает важность исходных признаков через
  permutation importance.
- `get_formula(feature_names=None)` - возвращает формулу итоговой модели.
- `to_json()` и `from_json()` - сохраняют и восстанавливают модель через JSON.

## Требования к данным

`X` должен быть двумерным массивом размера `n_samples x n_features`, а `y` -
одномерным массивом целевых значений. Для построения слоя нужно минимум два
признака. Данные внутри модели приводятся к типу `float`.

Пример формы данных:

```python
X.shape == (100, 4)
y.shape == (100,)
```

## Проверка работы

В папке есть файл `test_gmdh_module.py`. Он создает синтетический набор данных,
обучает модель и проверяет основные возможности библиотеки:

- обучение;
- предсказание;
- расчет метрик;
- важность признаков;
- получение формулы;
- сохранение и восстановление модели через JSON.

Запуск из папки `gmdh`:

```bash
python3 test_gmdh_module.py
```

При успешном запуске будет выведено примерно такое сообщение:

```text
GMDH module smoke test passed
Layers built: 5
Metrics: MSE=..., RMSE=..., MAE=..., R2=...
Top feature by permutation importance: x0
JSON round-trip max prediction difference: 0
```
